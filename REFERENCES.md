# References

This file lists the sources behind the facts in this course: the gdb manual and gdb's own
source and release notes, the Linux interfaces tdb is built on (`ptrace`, `waitpid`, signals,
`/proc`), the x86-64 architecture and ABI (`int3`, the debug registers, the calling
convention), the ELF and DWARF formats, the sanitizers, the tools around gdb (strace, binutils,
gdbserver, rr, QEMU, OpenOCD, LLDB), and the history the chapters tell. Use it to check a claim
or to read further.

Each source has two links: **original** (the live page) and **archived** (a snapshot in the
Internet Archive's [Wayback Machine](https://web.archive.org/), in case the original moves or
changes). For source code on GitHub, the archived link points to
[Software Heritage](https://archive.softwareheritage.org/), an archive of public source code.
Links into the gdb manual point at the current online manual; the course runs gdb 12.1, so
version facts cite the NEWS file at the gdb-12.1 tag. Program output, addresses and timings
shown in the chapters come from running the course's own code and aren't listed here.
